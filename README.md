# Data-Driven-Used-Car-Valuation
Developed a Machine Learning project to predict used-car selling prices based on vehicle features and specifications.
Collected and preprocessed used-car datasets by handling missing values, duplicates, and categorical data.
Performed Exploratory Data Analysis (EDA) to identify pricing trends based on brand, manufacturing year, fuel type, and kilometres driven.
Implemented and compared regression algorithms such as Linear Regression, Decision Tree, and Random Forest to identify the best-performing model.
Developed interactive dashboards using Power BI and a price prediction interface using Streamlit to provide estimated car prices and market insights.
